# Security Policy

## Supported Versions

This project does not currently publish versioned releases. Security fixes are
made to the latest code on the default branch. Older commits and branches are
not supported with security updates.

| Version | Supported |
| ------- | --------- |
| Latest code on the default branch | :white_check_mark: |
| Other versions and branches | :x: |

## Reporting a Vulnerability

Submit suspected security vulnerabilities through **Report a vulnerability**
on the repository's **Security** tab. Do not disclose vulnerabilities in public
issues or discussions.

Include steps to reproduce, the potential impact, and any relevant logs or
proof-of-concept details. Please avoid including real credentials or personal
data.

The maintainers will acknowledge a report within 7 calendar days and aim to
provide a status update at least every 14 calendar days while it is being
investigated. If the report is accepted, the maintainers will work with the
reporter on remediation and coordinated disclosure. If it is declined, the
reporter will be informed why. Response and remediation timelines may depend
on the severity and complexity of the issue.

If **Report a vulnerability** is unavailable, open a public issue asking
maintainers to enable private vulnerability reporting. Do not mention the
suspected vulnerability or include any details in that request.
